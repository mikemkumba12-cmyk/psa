# Archived documents

These files describe the earlier prototype of this application. They are kept for history only.

**Do not rely on them.** Several of their claims were not true of the code they described — for example, they report the system as "production ready", say documents were stored and linked to customer profiles, and describe dashboards and AI features that ran on browser-side demo data. The audit that found this is summarised in [`../IMPLEMENTATION_REPORT.md`](../IMPLEMENTATION_REPORT.md).
